แก้คำสั่งหรือรูปแบบคำตอบได้ แต่ห้ามลบหรือเปลี่ยนชื่อ {{PROJECT_ID}}, {{BUG_ID}}, {{BUGGY_SOURCE}} และไม่ต้องกรอกค่าเอง ระบบเติมข้อมูลของแต่ละ bug ให้อัตโนมัติ ก่อนส่ง prompt เดียวกันให้ AI ทุกรายการที่เลือก

เลือก “ระบุ Project / Bug เอง” เพื่อดู source ที่จะส่งให้ AI; ใน Auto ระบบจะดึง source แยกตาม Bug ระหว่าง campaign

โหมดนี้ใช้ algorithms ที่เลือกโดยไม่เรียก AI

Master Prompt และช่อง Source จะไม่ถูกใช้ ระบบยังดึงข้อมูลจาก Defects4J เพื่อสร้างและประเมิน test ตาม Project/Bug ที่เลือก
