### 1. SOURCE CODE ANALYSIS

### 2. TEST CASE DESIGN

- `testRecordSize`: default constructor; expects 512 from `TarBuffer.DEFAULT_RCDSIZE` as used by the constructor.
- `testEmptyStreamCanFinishAndWritesTwoRecords`: empty finish; expects two 512-byte EOF records.
- `testFinishIsNotRepeatable`: finish twice; expects `IOException` on the second call and unchanged byte count.
- `testFinishRejectsAnUnclosedEntry`: put a zero-size entry without closing it; finish rejects the open-entry state.
- `testCloseArchiveEntryRejectsMissingEntry`: close without a current entry; expects `IOException` and no output.
- `testCloseEntryRejectsIncompleteContent`: declare one byte but write none; close rejects the short content.
- `testWritePastDeclaredSizeIsRejected`: declare one byte and request two; write rejects the overrun.
- `testWritesExactlyDeclaredSizeAndClosesEntry`: one-byte entry; expected 512-byte header and 512-byte padded data record.
- `testWriteZeroBytesDoesNotOverrunEmptyEntry`: zero-size entry and zero-length write; close succeeds with the header record only.
- `testFragmentedWritesArePaddedOnEntryClose`: three bytes in fragments; close flushes one padded record after the header.
- `testFullRecordWriteCountsHeaderAndData`: 512 data bytes; expects header plus full data record.
- `testRecordBoundaryWriteCountsOnlyCompletedRecord`: after 512 bytes expects header plus one record; closing the final byte pads a second.
- `testGetCountMatchesBytesWrittenWhileWithinIntRange`: after empty finish, both counts are 1024.
- `testCreateArchiveEntryUsesRequestedName`: passes a name to the factory; checks the returned entry name.
- `testCreateArchiveEntryRejectedAfterFinish`: finished state causes the factory to throw.
- `testPutEntryRejectedAfterFinish`: finished state causes `putArchiveEntry` to throw.
- `testCloseFinishesEmptyArchive`: close finishes the empty archive; expects two EOF records.
