## 1. SOURCE CODE ANALYSIS

The tests cover method validation/support, Unix-mode bit encoding, attribute access, and name/directory/equality behavior.  
Extra-field tests exercise insertion order, replacement, front insertion, removal, and cloning.

## 2. TEST CASE DESIGN

- `testDefaultMethodAndSupport`: new entry; method is `-1` and unsupported, from field initialization.
- `testStoredMethod`: method `0`; supported and returned unchanged, from the STORED comparison.
- `testDeflatedMethod`: method `8`; supported, from the DEFLATED comparison.
- `testUnsupportedNonnegativeMethod`: method `9`; returned unchanged but unsupported.
- `testNegativeMethodRejected`: method `-1`; throws `IllegalArgumentException` and retains initial method `-1`.
- `testInternalAttributesRoundTrip`: set `-1`; getter returns the assigned int.
- `testExternalAttributesLongBoundary`: set `Long.MAX_VALUE`; getter returns the assigned long.
- `testExternalAttributesMinimumLong`: set `Long.MIN_VALUE`; getter returns the assigned long.
- `testUnixModeEncodesModeAndFatAttribute`: mode `0644` on a file; upper bits hold mode, read-only bit is set, and platform is UNIX.
- `testUnixModeWithWriteBitOmitsReadOnlyAttribute`: mode `0200`; the write bit prevents setting the DOS read-only bit.
- `testUnixModeDirectoryFlag`: mode `0755` on a directory; directory bit is set and mode is recoverable.
- `testUnixModeMasksToSixteenBits`: mode with bit 16 set; getter masks to the low 16 bits.
- `testDefaultPlatformHasNoUnixMode`: set external bits without setting UNIX platform; getter returns zero.
- `testExtraFieldInsertionAndReplacement`: duplicate header ID; map retains one entry and the replacement value.
- `testExtraFieldsPreserveInsertionOrder`: add two distinct IDs; values retain insertion order.
- `testAddAsFirstExtraFieldMovesReplacementToFront`: replace the second ID using front insertion; it becomes first with no duplicate.
- `testRemoveExtraField`: remove the sole field; collection is empty and lookup returns null.
- `testRemoveMissingExtraFieldRejected`: remove from an empty entry; source throws `NoSuchElementException`.
- `testExtraFieldArrayReplacement`: set a single-field array; getter and lookup return that field.
- `testNameDirectoryAndHashCode`: name ends in `/`; it is a directory and hash code equals the name hash.
- `testRegularNameIsNotDirectory`: name lacks trailing `/`; directory check is false.
- `testEqualsUsesName`: equal names compare equal; differing name and null compare false.
- `testLastModifiedDateMatchesEntryTime`: date getter constructs a `Date` from the entry time.
- `testClonePreservesAttributesAndName`: clone retains name, attributes, method, and equality.
- `testLocalFileExtraInitiallyEmpty`: no fields; local and central extra data are empty arrays.
