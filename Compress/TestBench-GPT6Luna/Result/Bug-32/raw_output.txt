### 2. TEST CASE DESIGN
- `testRecordSizeConstructorValue`: record size 128; constructor stores the supplied record size.
- `testDefaultRecordSize`: default constructor; getter returns `TarConstants.DEFAULT_RCDSIZE`.
- `testInitialAvailableIsZero`: before an entry is loaded, `entrySize` and `entryOffset` are zero.
- `testSkipNonpositiveValues`: skip 0 and -1; both follow the `n <= 0` branch and return 0.
- `testMarkNotSupported`: empty stream; source always returns false.
- `testMarkAndResetDoNotAlterEmptyStream`: empty stream; mark and reset do nothing, leaving available at 0.
- `testNextEntryAtEmptyInput`: empty input; incomplete record yields null.
- `testGenericNextEntryAtEmptyInput`: empty input; delegated next-entry call yields null.
- `testReadAtEmptyInput`: empty input; EOF is set and read returns -1.
- `testCanReadTarEntryData`: ordinary TarArchiveEntry; it is not GNU sparse, so result is true.
- `testCannotReadNonTarEntryData`: non-Tar ArchiveEntry; source returns false.
- `testCurrentEntryInitiallyNull`: before reading a header, current entry is null.
- `testMatchesRejectsTooShortLength`: length 0; it is below the required version-field end offset.
- `testMatchesRejectsNonTarSignature`: zero-filled signature; it matches none of the tested magic/version pairs.
- `testMatchesRejectsLengthJustBelowRequiredVersion`: required offset minus one; rejected by the initial length check.
- `testMatchesAcceptsPosixSignature`: exact POSIX magic and version at their declared offsets satisfy the first signature branch.
- `testCloseClosesUnderlyingStream`: close delegates to the wrapped stream.
