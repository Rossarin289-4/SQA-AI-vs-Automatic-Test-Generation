public class NodeTest {

    public void testAttributesSetReplaceAndRemove() throws Exception {

        node.attr("k", "one");
        assertEquals("one", node.attr("k"));
        node.attr("k", "two");
        assertEquals("two", node.attr("k"));
        node.removeAttr("k");
        assertFalse(node.hasAttr("k"));
        assertEquals("", node.attr("k"));

    public void testAttributesCollectionIsLive() throws Exception {

    public void testBaseUriTrimmedOnConstructionAndSetExactly() throws Exception {

        assertEquals("  custom  ", node.baseUri());
    }

    @Test
    public void testAbsoluteUrlFromRelativeAttribute() throws Exception {

    public void testAbsoluteUrlAlreadyAbsolute() throws Exception {

        parent.appendChild(second);

        assertSame(second, parent.childNode(1));
        assertEquals(Integer.valueOf(0), first.siblingIndex());
        assertEquals(Integer.valueOf(1), second.siblingIndex());

    public void testParentAndOwnerDocument() throws Exception {

        document.appendChild(child);
        assertSame(document, child.parent());
        assertSame(document, child.ownerDocument());
        assertSame(document, document.ownerDocument());

    @Test
    public void testSiblingBoundariesAndMiddle() throws Exception {
        Element parent = new Element(Tag.valueOf("div"), "");
        Node first = new TextNode("a", "");
        Node middle = new TextNode("b", "");
        Node last = new TextNode("c", "");
        parent.appendChild(first);
        parent.appendChild(middle);
        parent.appendChild(last);
        assertNull(first.previousSibling());
        assertSame(middle, first.nextSibling());
        assertSame(first, middle.previousSibling());
        assertSame(last, middle.nextSibling());

        assertNull(last.nextSibling());

    @Test
    public void testRemoveReindexesRemainingChildren() throws Exception {
        Element parent = new Element(Tag.valueOf("div"), "");
        Node first = new TextNode("a", "");

        parent.appendChild(first);
        parent.appendChild(removed);
        parent.appendChild(last);

        assertNull(removed.parent());

        assertEquals(Integer.valueOf(1), last.siblingIndex());

        assertSame(newNode, parent.childNode(0));

        assertSame(parent, newNode.parent());

    public void testOuterHtmlAndToStringAgreeForTextNode() throws Exception {

        assertEquals("sample", node.outerHtml());

    }

### 1. SOURCE CODE ANALYSIS
Tests cover attribute access/mutation, base URI and URL resolution, child relationships and reindexing, cloning, equality/hash code, and serialization.
Tree tests use Elements as configured parents, with the exact same child instances appended before querying them.

### 2. TEST CASE DESIGN
- `testAttributesSetReplaceAndRemove`: set, replace, then remove `k`; reads return `one`, `two`, then absent/empty.
- `testAttributesCollectionIsLive`: one stored attribute gives size 1; removal gives size 0.
- `testBaseUriTrimmedOnConstructionAndSetExactly`: constructor trims the URI; setter retains its supplied spaces.
- `testAbsoluteUrlFromRelativeAttribute`: `../next` resolves from `/dir/page` to `/next`.
- `testAbsoluteUrlAlreadyAbsolute`: absolute HTTPS value is returned unchanged as an external form.
- `testAbsoluteUrlQueryKeepsBasePath`: query-only reference uses the base path workaround.
- `testAbsoluteUrlMissingOrInvalid`: missing attribute and unparseable relative URL both yield empty string.
- `testAbsoluteAttributeShortcutAndOrdinaryMissingAttribute`: `abs:` resolves the relative link; absent ordinary attribute is empty.
- `testChildNodesAndIndicesAfterAppending`: two appended children occupy indices 0 and 1.
- `testParentAndOwnerDocument`: appended element's parent and owner are the document; document owns itself.
- `testSiblingBoundariesAndMiddle`: first/last sibling boundaries are null; middle links and sibling count reflect the three children.
- `testRemoveReindexesRemainingChildren`: removing the middle child leaves two children and assigns the last index 1.
- `testReplaceWithUpdatesTree`: replacement occupies the old index; old node is detached and new node attached.
- `testChildCanBeReparented`: moving the same child empties its former parent and attaches it to the latter.
- `testCloneIsIndependentAndOrphaned`: clone has no parent, retains copied state, and attribute changes do not affect original.
- `testEqualsUsesIdentity`: source returns true for self and false for a distinct node.
- `testHashCodeMatchesAttributesAndParentState`: equal empty attributes produce matching hashes; adding an attribute changes the hash.
- `testOuterHtmlAndToStringAgreeForTextNode`: text node serializes as its text, and `toString()` delegates to outer HTML.

### 4. DEFECT DETECTION STRATEGY
The assertions pin observable URL resolution, tree mutation/indexing, clone independence, and attribute/serialization behavior. They exercise configured node trees rather than relying only on empty defaults.
