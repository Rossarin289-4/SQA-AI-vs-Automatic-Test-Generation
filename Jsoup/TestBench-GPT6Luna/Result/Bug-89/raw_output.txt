- `testSetValueReturnsPreviousValue`: old and new strings; setter returns the old value and stores the new one.

- `testGetValueNullIsEmptyValue`: null initial value; getter returns `checkNotNull`'s empty value.
- `testHtmlEscapesAttributeValue`: ampersand in a value; HTML attribute escaping produces `&amp;`.
- `testHtmlRendersEmptyBooleanAttributeCollapsed`: empty `disabled` value; boolean attribute is rendered without a value.
- `testHtmlRendersBooleanNameValueCollapsed`: case-insensitive matching boolean value; attribute collapses.
- `testHtmlDoesNotCollapseOrdinaryAttribute`: empty ordinary value; it is rendered with `=""`.
