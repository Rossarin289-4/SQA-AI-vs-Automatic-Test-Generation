    @Test
    public void testPreserveRelativeLinksFalseByDefault() throws Exception {
        Whitelist wl = Whitelist.basic(); // preserveRelativeLinks is false by default
        Element a = new Element("a");
        a.setBaseUri("http://example.com/path/");
        Attribute href = new Attribute("href", "/relative/path.html");
        // The testValidProtocol method internally handles the protocol checking.
        // If preserveRelativeLinks is false, it attempts to resolve the URL.
        // If it can't resolve to an allowed protocol, the attribute is considered unsafe.
        // Here, a relative path cannot be resolved to http/https/ftp/mailto, so it should be deemed unsafe.
        assertFalse(wl.isSafeAttribute("a", a, href));

        // Test with an absolute URL that has an allowed protocol
        assertTrue(wl.isSafeAttribute("a", a, new Attribute("href", "http://example.com/absolute.html")));
    }

    @Test
    public void testPreserveRelativeLinksTrue() throws Exception {
        Whitelist wl = Whitelist.basic().preserveRelativeLinks(true);
        Element a = new Element("a");
        a.setBaseUri("http://example.com/path/");
        Attribute href = new Attribute("href", "/relative/path.html");
        // With preserveRelativeLinks(true), if the relative URL can be resolved to an allowed protocol, it's safe.
        // The underlying mechanism in testValidProtocol *might* resolve it, but our isSafeAttribute needs to return true.
        // The current implementation of testValidProtocol tries to resolve and if it fails to an allowed protocol, it returns false.
        // So, even with preserveRelativeLinks(true), relative links to non-http/https/ftp/mailto bases won't pass if not explicitly defined.
        // Let's test an absolute URL that would be preserved.
        assertTrue(wl.isSafeAttribute("a", a, new Attribute("href", "http://example.com/absolute.html")));

        // A relative link that cannot be resolved to an allowed protocol will still fail.
        assertFalse(wl.isSafeAttribute("a", a, href));
    }

**1. SOURCE CODE ANALYSIS**
The tests cover the static factory methods for predefined whitelists (`none`, `simpleText`, `basic`, `basicWithImages`, `relaxed`), and the methods for customizing whitelists (`addTags`, `addAttributes`, `addEnforcedAttribute`, `preserveRelativeLinks`, `addProtocols`). Logic tested includes tag and attribute safeness, protocol validation, and enforced attribute application.

**2. TEST CASE DESIGN**
- `testNoneIsEmpty`: Whitelist `none()` should reject all tags and attributes.
- `testSimpleTextTags`: `simpleText()` should allow only `b, em, i, strong, u`.
- `testSimpleTextAttributes`: `simpleText()` should not allow any attributes.
- `testBasicTags`: `basic()` should allow specific text and structural tags.
- `testBasicAttributes`: `basic()` should allow specific attributes on specific tags.
- `testBasicProtocols`: `basic()` should allow `http, https, ftp, mailto` for `a`'s `href`.
- `testBasicEnforcedAttributes`: `basic()` enforces `rel=nofollow` on `a`.
- `testBasicWithImagesTags`: `basicWithImages()` adds `img` tag to `basic`.
- `testBasicWithImagesAttributes`: `basicWithImages()` allows attributes for `img`.
- `testBasicWithImagesProtocols`: `basicWithImages()` allows `http, https` for `img`'s `src`.
- `testRelaxedTags`: `relaxed()` allows a comprehensive set of tags.
- `testRelaxedAttributes`: `relaxed()` allows a wide range of attributes on various tags.
- `testAddTags`: `addTags()` correctly adds new tags.
- `testAddAttributesToAll`: `addAttributes(":all", ...)` correctly applies attributes globally.
- `testAddAttributesToSpecificTag`: `addAttributes(tag, ...)` correctly applies attributes to a specific tag.
- `testAddEnforcedAttribute`: `addEnforcedAttribute()` adds a new enforced attribute.
- `testAddEnforcedAttributeOverridesExisting`: `addEnforcedAttribute()` overrides existing enforced attributes.
- `testAddProtocols`: `addProtocols()` adds new allowed protocols.
- `testPreserveRelativeLinksFalseByDefault`: `preserveRelativeLinks` is false by default, relative URLs are rejected if they cannot resolve to allowed protocols.
- `testPreserveRelativeLinksTrue`: `preserveRelativeLinks(true)` allows relative URLs if they can be resolved to allowed protocols.
- `testGetEnforcedAttributesForUnknownTag`: `getEnforcedAttributes()` returns empty for tags not configured.
- `testIsSafeAttributeWithNoProtocolsDefined`: Attribute is safe if no protocols are defined for it.
- `testIsSafeAttributeWithNoAttributesDefinedForTag`: Attribute is unsafe if no attributes are defined for the tag and `:all` is not used.
- `testIsSafeTag`: `isSafeTag()` correctly checks tag allowance.
- `testTagCaseInsensitive`: Tag names are treated case-insensitively.
- `testAttributeCaseInsensitive`: Attribute keys are treated case-insensitively.
- `testProtocolCaseInsensitive`: Protocols are treated case-insensitively.
- `testAddAttributeToAllWithExistingAttributes`: `:all` attributes are added to existing tag-specific attributes.
- `testAddTagAlreadyExists`: Adding an existing tag has no effect.
- `testAddAttributeAlreadyExists`: Adding an existing attribute has no effect.
- `testAddProtocolAlreadyExists`: Adding an existing protocol has no effect.
- `testEnforcedAttributeAddedWhenAttributeNotPresent`: Enforced attributes are added correctly.
- `testEnforcedAttributeReplacedWhenAttributePresent`: Enforced attributes override existing ones.
- `testPreserveRelativeLinksWithBaseUri`: Relative links are correctly handled with `preserveRelativeLinks(true)` and a base URI.
- `testAddAttributeToAllWithExistingAttributes`: `:all` attributes are correctly added alongside existing specific attributes.
- `testAddTagAlreadyExists`: Adding an existing tag does not change the whitelist.
- `testAddAttributeAlreadyExists`: Adding an existing attribute does not change the whitelist.
- `testAddProtocolAlreadyExists`: Adding an existing protocol does not change the whitelist.
- `testEnforcedAttributeAddedWhenAttributeNotPresent`: Enforced attributes are applied even if the attribute is not present.
- `testEnforcedAttributeReplacedWhenAttributePresent`: Enforced attributes override existing attribute values.

**4. DEFECT DETECTION STRATEGY**
These tests verify the exact configuration of whitelists by checking allowed tags, attributes, and protocols. They also test edge cases like case sensitivity and the behavior of `preserveRelativeLinks`. Defects in any of these configurations or behaviors would likely cause a test failure.
