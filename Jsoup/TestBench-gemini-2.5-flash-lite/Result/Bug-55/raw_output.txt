   - `testDataStateConsumeToAmpersand`: Input "Hello&World", Expected "Hello", Derived by `r.consumeData()`. State becomes `CharacterReferenceInData`.
   - `testDataStateConsumeToLessThan`: Input "Hello<World", Expected "Hello", Derived by `r.consumeData()`. State becomes `TagOpen`.
   - `testDataStateNullChar`: Input "Hello\u0000World", Expected `replacementChar`, Derived by emitting `nullChar`. State remains `Data`.
   - `testDataStateEOF`: Input "", Expected EOF Token, Derived by `r.current() == eof`.
   - `testCharacterReferenceInData`: Input "&nbsp;", Expected character data (non-empty), Derived by `readCharRef`. State becomes `Data`.
