- `testAppendPrimitiveInt`: append 7; expects `n=7,` from field prefix, numeric output, and field separator.
- `testAppendNegativeIntEdge`: append `Integer.MIN_VALUE`; expects its standard decimal form and separator.

- `testAppendNullObject`: null object value; expects the default null text.
- `testAppendObjectDetail`: detail mode for `"text"`; expects its string value.
- `testAppendObjectSummary`: summary mode for `"text"`; expects `<String>` from its short class name.
- `testAppendObjectNullDetailUsesDefault`: null detail request; expects default full-detail behavior.
- `testAppendEmptyObjectArrayDetail`: empty array detail; expects default array braces.
- `testAppendObjectArrayWithNull`: two elements including null; expects array delimiters and null text.
- `testAppendObjectArraySummarySize`: two-element array summary; expects size 2.
- `testAppendSuperExtractsContent`: extracts content between `[` and `]` and appends a separator.
- `testAppendSuperIgnoresNull`: null input leaves the buffer unchanged.
- `testAppendToStringExtractsMultipleFields`: extracts the enclosed fields and adds the default trailing separator.
- `testAppendToStringIgnoresMissingContentStart`: absent `[` yields no extracted content.
- `testAppendStartWithDefaultStyle`: expects class name, identity hash, and content start for the supplied object.
- `testAppendStartWithSimpleStyle`: simple style emits no start prefix.
- `testAppendStartIgnoresNullObject`: null object leaves the buffer unchanged.
- `testAppendEndRemovesTrailingSeparator`: removes the trailing comma and appends `]`.
- `testAppendEndPreservesNonSeparatorSuffix`: leaves a non-comma suffix intact before appending `]`.
- `testAppendEndSimpleStyle`: simple style keeps the comma and appends its empty content end.
- `testAppendEndMultiLineStyle`: removes the comma and appends the platform line separator and closing bracket.
