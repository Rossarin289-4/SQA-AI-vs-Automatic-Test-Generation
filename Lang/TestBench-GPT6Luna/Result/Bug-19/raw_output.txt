## 1. SOURCE CODE ANALYSIS
The sole public method, `translate`, checks the ampersand/hash prefix, optional hexadecimal marker, allowed digit forms, and optional semicolon.  
It parses an integer, writes either one UTF-16 unit or a supplementary pair, and returns the consumed input length; invalid parses return zero.

## 2. TEST CASE DESIGN
- Decimal with semicolon: `"&#65;"` → 5 and `"A"`; digit length plus prefix and semicolon.
- Decimal without semicolon: `"&#65"` → 4 and `"A"`; no terminator to consume.
- Lowercase hex prefix: `"&#x41;"` → 6 and `"A"`; hex prefix and terminator included.
- Uppercase hex prefix: `"&#X41;"` → 6 and `"A"`; uppercase prefix follows the same branch.
- Lowercase hex digits: `"&#x4a;"` → 6 and `"J"`; hexadecimal `4a` is decimal 74.
- Uppercase hex digits: `"&#x4A;"` → 6 and `"J"`; hexadecimal `4A` is decimal 74.
- Nonzero index: `"z&#66;"`, index 1 → 5 and `"B"`; consumed count begins at the supplied entity index.
- Ampersand only: `"&"` → 0 and empty output; the required prefix cannot be complete.
- Non-entity: `"abc"` → 0 and empty output; first character is not `&`.
- Invalid decimal: `"&#q;"` → 0 and empty output; parsing the empty digit span fails.
- Invalid hex: `"&#xg;"` → 0 and empty output; parsing the empty hexadecimal digit span fails.
- Decimal zero: `"&#0;"` → 4 and NUL; parsed value is zero and the semicolon is consumed.
- Largest BMP decimal value: `"&#65535;"` → one character with value 65535; the value remains in the single-unit branch.
- First supplementary decimal value: `"&#65536;"` → a two-unit string encoding code point 65536.
- First decimal value above integer maximum: `"&#2147483648;"` → 0 and empty output; `Integer.parseInt` rejects it.
- Largest BMP hex value: `"&#xFFFF;"` → one character with value 65535.
- First supplementary hex value: `"&#x10000;"` → two UTF-16 units encoding code point 65536.
- Beyond Unicode range: `"&#x110000;"` → `IllegalArgumentException`; `Character.toChars` rejects the parsed invalid code point.
- Semicolon before trailing text: `"&#7;z"` → 5 and BEL; semicolon counts in the consumed length.
- No semicolon before trailing text: `"&#7z"` → 3 and BEL; `z` is not a decimal digit and is not consumed.
