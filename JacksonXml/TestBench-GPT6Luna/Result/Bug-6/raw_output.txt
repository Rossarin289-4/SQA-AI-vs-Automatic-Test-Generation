- `testRepeatedFieldNameAcceptsValueAfterEachName`: each repeated field name is followed by a value, satisfying context state.
- `testWriteIntegerAndBooleanValues`: writes signed integer endpoints and a boolean; operations complete in object context.

- `testAttributeStringAndInteger`: writes named values with attribute mode; output methods consume the configured names.
- `testUnwrappedFlagAppliesToOneValue`: first string consumes the unwrapped flag; the following string uses normal element output.
- `testCDataAndCharacterArraySlice`: CDATA string and selected character slice are submitted through their respective paths.
