### 2. TEST CASE DESIGN
- `testEmptyMapBasics`: empty map; size 0, empty true, missing lookups null/false; follows the empty branches.
- `testNullKeyAndValue`: null key/value then replacement; verifies stored null mapping and old-value return.
- `testReplaceExistingValueAndPreserveSize`: existing key; replacement returns old value and leaves size 1.
- `testThreeFlatEntriesIncludingNull`: three mappings including a null key; verifies lookups and value search.
- `testCrossingThreeEntryLimitAndReplacing`: fourth insertion triggers delegate mode; size and replacement behavior follow map storage.
- `testRemoveFirstMiddleAndLastFlatEntry`: remove first, then last and remaining flat entries; asserts values and sizes.
- `testRemoveNullKeyFromMiddle`: removes a null key from three flat entries; verifies surviving mappings.
- `testRemoveMissingKeyDoesNotChangeMap`: absent key returns null and leaves the existing mapping.
- `testPutAllFromSmallMap`: two-entry source copied by constructor; verifies size and values.
- `testPutAllAtAndAboveFourEntries`: four-entry `putAll` into a nonempty map; verifies all five mappings.
- `testClearAfterDelegateModeAllowsReuse`: clear after four insertions, then reuse; verifies empty and subsequent state.
- `testMapIteratorSetValueAndReset`: iterator key/value, value replacement, and reset to first mapping.
- `testMapIteratorRemoveUpdatesMap`: iterator removal; verifies map state and next key.
- `testEntrySetRemovalAndLiveSize`: entry-set removal; verifies the view size and map contents.
- `testKeySetRemoveAndValuesContain`: key and value view queries and key removal update the map.
- `testEntryIteratorEntryViewMutatesMap`: entry iterator returns key/value and `setValue` changes the map.
- `testEqualityAndHashCodeForFlatMap`: flat-map equality and standard hash code, then inequality on value mismatch.
- `testToStringForEmptyAndMultipleEntries`: empty representation and insertion-order flat representation.
- `testCloneIsIndependentForFlatStorage`: clone initially equals source; changing clone leaves source unchanged.
- `testEqualsAndHashCodeAfterDelegateTransition`: four entries; delegate-mode equality and hash code match `HashMap`.
