        // Example from Wikipedia: N=10, m=3, k=4. P(X <= 1) = P(X=0) + P(X=1)
        // P(X=0) = C(3,0)*C(7,4)/C(10,4) = 1 * 35 / 210 = 35/210
        // P(X=1) = C(3,1)*C(7,3)/C(10,4) = 3 * 35 / 210 = 105/210
