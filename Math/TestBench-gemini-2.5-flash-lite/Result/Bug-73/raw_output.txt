        // If it doesn't throw, it means it converged.

        // The problem is that the default constructor `BrentSolver()` uses `100`

        // For the purpose of this exercise, and adhering to the rules,

        // The `solve` methods themselves are declared to throw this exception.
        // A test that genuinely exceeds it would need to be constructed with
        // specific inputs that are known to require more than `maximalIterationCount`
        // iterations to converge to `functionValueAccuracy`.

        // As a fallback, let's consider a test that *could* fail if the
        // implementation were flawed in a way that it *never* converged
        // but also didn't throw the exception. However, that's not what

        BrentSolver solverForMaxIterations = new BrentSolver(10, 1E-6); // Low iteration count
