        // The condition `yInitial * yMin < 0` is false.
        // It should call `solve(min, yMin, max, yMax, initial, yInitial)` which is `solve(0, -4, 3, 5, 1, -3)`

        // If we call solve(0, 3, 1), it checks endpoints, yMin=-4, yMax=5. Brackets.
        // Then it checks initial=1, yInitial=-3.
        // if yInitial * yMin < 0 (-3 * -4 > 0) false
        // if yInitial * yMax < 0 (-3 * 5 < 0) true. calls solve(1, -3, 3, 5, 1, -3).
        // This is one of the private solve calls.

        // Let's test the case: "reduce interval if min and initial bracket the root"
        // This means yMin * yInitial < 0.
        // Consider f(x) = x - 2. Root at 2.
        // min = 0, yMin = -2. initial = 3, yInitial = 1. yMin * yInitial < 0 is true.
        // Calls solve(0, -2, 3, 1, 0, -2). This is the private method.
        // For the public method solve(min, max, initial):
        UnivariateRealFunction linear = new UnivariateRealFunction() {
            public double value(double x) throws FunctionEvaluationException {
                return x - 2;
            }
        };
        BrentSolver solver3 = new BrentSolver(linear);
        // min=0, max=3, initial=1. yMin=-2, yMax=1, yInitial=-1.
        // yInitial * yMin = (-1) * (-2) = 2 > 0.
        // yInitial * yMax = (-1) * (1) = -1 < 0. Calls solve(1, -1, 3, 1, 1, -1)
        // This is the `solve(initial, yInitial, max, yMax, initial, yInitial)` branch.
        // Let's construct the scenario for `solve(min, yMin, initial, yInitial, min, yMin)`
        // This is called when yMin * yInitial < 0.
        // min = 0, yMin = -2. initial = 3, yInitial = 1.
        // So, call solve(0, 3, 1) with f(x) = x - 2.
        // yMin = -2, yMax = 1, yInitial = -1.
        // Check `yInitial * yMin < 0` which is `(-1) * (-2) < 0` -> `2 < 0` which is false.
        // Check `yInitial * yMax < 0` which is `(-1) * (1) < 0` -> `-1 < 0` which is true.
        // It calls `solve(initial, yInitial, max, yMax, initial, yInitial)` which is `solve(1, -1, 3, 1, 1, -1)`.

        // Let's try the actual public method that calls the helper: `solve(min, max)`
        // The requirement is that `yMin * yMax < 0`.
        // For f(x) = x - 2, solve(0, 3). yMin=-2, yMax=1. Signs are opposite.
        // It should call `solve(min, yMin, max, yMax, min, yMin)` -> `solve(0, -2, 3, 1, 0, -2)`.
        assertEquals(2.0, solver3.solve(0.0, 3.0), 1E-6);
