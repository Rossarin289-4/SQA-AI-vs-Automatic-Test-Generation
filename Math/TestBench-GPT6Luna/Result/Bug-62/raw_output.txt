    private static class TestOptimizer implements BaseUnivariateRealOptimizer<UnivariateRealFunction> {
        private int maxEvaluations;
        private int evaluations;
        private double failAt = Double.NaN;
        private double convergeAt = Double.NaN;
        private boolean failEveryTime;

        public void setConvergenceChecker(ConvergenceChecker<UnivariateRealPointValuePair> checker) { }
        public ConvergenceChecker<UnivariateRealPointValuePair> getConvergenceChecker() { return null; }
        public int getMaxEvaluations() { return maxEvaluations; }
        public int getEvaluations() { return evaluations; }
        public void setMaxEvaluations(int value) { maxEvaluations = value; }

        public UnivariateRealPointValuePair optimize(UnivariateRealFunction f, GoalType goal,
                                                     double min, double max, double start)
            throws FunctionEvaluationException {
            evaluations = 1;
            if (failEveryTime || start == failAt) {
                throw new FunctionEvaluationException(start);
            }
            if (start == convergeAt) {
                throw new ConvergenceException();
            }
            return new UnivariateRealPointValuePair(start, f.value(start));
        }
    }

        public double nextDouble() { return values[index++]; }

### 1. SOURCE CODE ANALYSIS
This class delegates checker and evaluation-limit accessors, initializes and copies the optimum array, and runs the optimizer once per start.  
The tests exercise best-first sorting for both goals, null entries after caught failures, and the exception when no start converges.

### 2. TEST CASE DESIGN
- `testConstructorAndEvaluationDefaults`: before optimization, both counters are 0 from their default initialization.
- `testSetMaxEvaluationsDelegatesAndReadsBack`: 17 is stored locally and passed to the wrapped optimizer.
- `testSetMaxEvaluationsAtZero`: 0 is stored locally and passed to the wrapped optimizer.
- `testSetMaxEvaluationsAtMaximumInteger`: the maximum `int` is stored and delegated unchanged.
- `testSetMaxEvaluationsAtMinimumInteger`: the minimum `int` is stored and delegated unchanged.
- `testCheckerDelegation`: a null checker is delegated and read back from the test optimizer.
- `testGetOptimaBeforeOptimizeThrows`: the source throws `MathIllegalStateException` while `optima` is null.
- `testSingleStartReturnsAndStoresOptimum`: the one start is 3; the test optimizer returns that point and counts one evaluation.
- `testOptimizeConvenienceUsesMidpoint`: the overload computes `2 + 0.5 * (8 - 2) = 5`.
- `testOptimaArrayIsDefensiveCopy`: modifying the returned array does not modify the stored array clone source.
- `testMinimizeSortsBestFirstAcrossStarts`: minimizing sorts values 0, 5, 8 in ascending order.
- `testMaximizeSortsBestFirstAcrossStarts`: maximizing sorts values 5, 2, 0 in descending order.
- `testFunctionEvaluationFailureLeavesNullAfterSuccessfulOptimum`: the run at 5 throws and is stored as null; the successful point 2 sorts first.
- `testConvergenceFailureLeavesNullAfterSuccessfulOptimum`: the run at 5 throws convergence and is stored as null; point 2 sorts first.
- `testAllFailuresThrowConvergenceException`: both runs fail, so no first optimum exists; two optimizer calls contribute one evaluation each.
- `testOneStartDoesNotUseRandomGenerator`: with one start, the supplied start value 7 is used and the null generator is not read.

### 4. DEFECT DETECTION STRATEGY
Pin delegated state, total evaluation accounting, sorting direction and null placement, defensive copying, and failure handling.  
The deterministic optimizer and random sequence make each configured multi-start path reproducible.
