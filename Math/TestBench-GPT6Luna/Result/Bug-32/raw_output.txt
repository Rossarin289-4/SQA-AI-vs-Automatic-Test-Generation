### 2. TEST CASE DESIGN
- `testEmptyTreeHasNoVertices`: default region; empty tree yields a zero-length vertex array.
- `testWholeSpaceTreeHasNoVertices`: true leaf tree; no boundary yields zero loops.
- `testBoxVerticesFormOneLoop`: finite 2-by-1 box; one loop of four points.
- `testBoxVerticesHaveExpectedCoordinates`: bounds 0..2 and 0..1; traces the box boundary points in trigonometric order.
- `testBoxVerticesReturnDistinctOuterArrays`: repeated calls clone the outer array but retain the cached loop array.
- `testBuildNewFromWholeSpaceTree`: builds from a true leaf; resulting boundary has zero loops.
- `testBuildNewFromBoxTree`: builds from a box tree; resulting boundary has one four-vertex loop.
- `testGetVerticesForZeroWidthBox`: equal x bounds; degenerate boundary produces no closed loop.
- `testGetVerticesForNegativeWidthBounds`: reversed x bounds; no bounded polygon loop is produced.
- `testGetVerticesForUnitBox`: unit bounds; one four-point loop.
- `testGetVerticesForTranslatedBox`: negative and positive bounds; verifies loop count, length, and first point.
- `testWholeSpaceBoxBoundsHasNoVertices`: infinite bounds; no finite boundary vertices are formed.
