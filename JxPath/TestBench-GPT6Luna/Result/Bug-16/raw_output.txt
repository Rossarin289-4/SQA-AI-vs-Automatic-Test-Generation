### 2. TEST CASE DESIGN
- `testNameAndNamespaceForNamespacedElement`: `p:item` in `urn:x`; QName prefix/local name and namespace URI follow DOM namespace data.
- `testNodeNameTestMatchesLocalNameAndNamespace`: same local name and URI matches; a different local name does not.
- `testNodeTypeTestsForTextCommentAndProcessingInstruction`: text, comment, and PI match their respective node types; text does not match comment.
- `testProcessingInstructionTargetTest`: matching target succeeds and a different target fails.
- `testLeafLengthAndPointerValues`: childless element is a leaf, has length one, and exposes its original node.
- `testChildMakesElementNonLeafAndStringValue`: text child makes the element non-leaf; default trimming yields `hello`.
- `testValuePreservesTextWhenXmlSpacePreserve`: inherited `xml:space="preserve"` retains whitespace.
- `testCommentValueIsTrimmed`: comment data is trimmed to `note`.
- `testSetTextValueAndRemoveEmptyText`: nonempty text replaces the node value; setting empty text removes the node.
- `testSetElementValueReplacesChildrenWithText`: old children are replaced by one text child with value `new`.
- `testDefaultAndPrefixedNamespaceResolution`: explicit default/prefixed declarations resolve; unknown prefix returns null.
- `testNamespaceResolverIsCached`: repeated resolver access returns the cached resolver.
- `testAttributeCreationAndRetrieval`: creating absent `key` yields an empty attribute on the element.
- `testRemoveChildNode`: removing an attached child leaves the parent with no children.
- `testCannotRemoveRootNode`: a parentless document removal throws `JXPathException`.
- `testPathForIdEscapesQuotes`: apostrophe in an ID is emitted as `&apos;`.
- `testPrefixAndLocalNameFallback`: colon-delimited node name yields prefix `p` and local name `item`.
- `testIdentityEqualityAndHashCode`: pointers to the same node compare equal; hash uses node identity.
- `testCompareChildPointersInDocumentOrder`: sibling order gives `-1`, reverse gives `1`, and same-node comparison gives `0`.
- `testAttributePrecedesChildInComparison`: attribute pointer sorts before a child pointer.
- `testChildAndAttributeIteratorsFindConfiguredNodes`: iterator position one returns the attached child and the configured attribute.
- `testLanguageUsesNearestXmlLangPrefixCaseInsensitively`: `en-US` matches `EN` and does not match `fr`.
