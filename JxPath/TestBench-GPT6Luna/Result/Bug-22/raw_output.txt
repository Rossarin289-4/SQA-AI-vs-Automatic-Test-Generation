## 1. SOURCE CODE ANALYSIS
Tests target DOM node identity, names/namespaces, node tests, value mutation, attributes, removal, paths, ordering and language matching.
The chosen cases exercise element/text/comment/PI distinctions, namespace declarations, and configured DOM relationships.

## 2. TEST CASE DESIGN
- `testBasicsAndLeafState`: attached then childless/with-child element; checks identity, fixed pointer flags/length, and `hasChildNodes`.
- `testQNameAndStaticNameParts`: namespaced `p:item`; derives prefix, local name, and URI from DOM.
- `testUnprefixedQNameParts`: no-namespace element; derives null prefix/URI and local node name.
- `testNodeTypeTests`: text/comment/PI/element; checks the source's node-type switch and null-test behavior.
- `testProcessingInstructionTargetTest`: matching and nonmatching PI targets.
- `testNodeNameTest`: exact namespaced QName matches and another local name does not.
- `testNamespaceLookupsIncludingReservedPrefixes`: declared prefixes/default namespace and reserved `xml`/`xmlns`; undeclared prefix resolves null.
- `testNamespaceResolverCachesOnPointer`: source retains the initialized resolver instance.
- `testValueAndXmlSpacePreserve`: `xml:space="preserve"` retains text whitespace.
- `testCommentValueIsTrimmed`: comment value is trimmed by `getValue`.
- `testSetTextValueAndRemoveOnEmpty`: nonempty text replaces node value; empty text removes its node from parent.
- `testSetElementTextContents`: scalar element replacement removes old children and creates one text child.
- `testSetElementFromElementClonesChildren`: element assignment copies its child under target.
- `testAttributeCreationReturnsAttachedAttributePointer`: created attribute has empty value and returned pointer refers to the attached attribute.
- `testCreateAttributeRejectsUnknownPrefix`: unresolved prefixed attribute creation throws `JXPathException`.
- `testRemoveAttachedNode`: removing a child detaches it from its parent.
- `testRemoveRootThrows`: removing a document root with no parent throws `JXPathException`.
- `testPathForTextAndExplicitId`: single text sibling gets position 1; explicit ID yields the source's ID path format.
- `testPointerIdentityEqualityAndHash`: pointers over the same DOM node compare equal and share node hash; a different node does not.
- `testCompareChildNodeOrder`: sibling traversal order yields negative/positive comparisons, with identical nodes returning zero.
- `testLanguageMatchingCaseInsensitively`: inherited `xml:lang` prefix comparison is case-insensitive.
