2. TEST CASE DESIGN

- Default state: default name `"*"`, zero length/count, null values, leaf, actual false, container true; read directly from initial fields and methods.
- Set property name to `"alpha"`: name and property name both become `"alpha"`.
- Set name attribute to `"field"`: property name and QName local name both become `"field"`.
- Set property index to `3`: no-op; default name and whole-collection index remain unchanged.
- Default index: collection is false because the index equals `WHOLE_COLLECTION`.
- Index `0`: collection is true and index remains zero.
- Index `1`: collection is true and index remains one.
- Index `-1`: collection is true because it differs from `WHOLE_COLLECTION`.
- Value pointer after setting `"beta"`: its name uses the current property name.
- Property names: returned array has length zero.
- Property count: returns zero.
- Set value with null parent: throws `JXPathInvalidAccessException`.
- Name-attribute value `"a'b"`: path replaces the single quote with `&apos;`.
- Name-attribute value containing a double quote: path replaces it with `&quot;`.
- Name-attribute path at index zero: renders the one-based index `[1]`.
- Name-attribute path at index two: renders the one-based index `[3]`.
