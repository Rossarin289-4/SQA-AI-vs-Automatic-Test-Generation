## 1. SOURCE CODE ANALYSIS
Tests cover node matching, names and namespaces, string values and mutation, paths, equality, removal, and child/attribute ordering.

## 2. TEST CASE DESIGN
- `testBasicPointerState`: root element; checks base/immediate node, state flags, length, leaf state, and element string value.
- `testTestNodeNullAndElementName`: matching element names and a nonmatching name; traces `NodeNameTest` checks.
- `testNodeTypeDistinguishesDocumentAndText`: document matches node type; text matches text type only.
- `testCommentTypeTest`: comment matches comment type but not PI.
- `testProcessingInstructionTargetTest`: target `go` matches only the identical PI target; name uses that target.
- `testNameAndNamespaceHelpers`: prefixed name and declaration yield prefix `p`, local name `thing`, and `urn:test`.
- `testNamespaceDefaultsAndReservedPrefixes`: default and declared namespace resolutions plus fixed `xml`/`xmlns` URIs and unresolved null.
- `testLeafValueAndStringMutation`: text node trims its initial value and stores the replacement.
- `testEmptyTextValueRemovesTextNode`: empty replacement removes the text child.
- `testSetElementValueReplacesChildren`: removes previous child and appends the replacement text.
- `testXmlSpacePreserveAndCommentValue`: `xml:space=preserve` keeps whitespace; comment value trims it.
- `testAsPathForRootAndSameNameSiblings`: root path is empty and second same-name child is `/item[2]`.
- `testIdPathEscapesQuotes`: both quote characters are escaped in ID path.
- `testEqualityUsesNodeIdentity`: pointers compare equal only when referencing the identical DOM node; hash uses node identity.
- `testRemoveAttachedNode`: removal detaches the child from its parent.
- `testRemoveDocumentRootThrows`: document has no parent, so removal throws `JXPathException`.
- `testAttributeAndChildIterators`: configured attribute and element child are found at position one.
- `testCompareChildOrderAndIdentity`: child order yields -1/1 and identical pointers yield zero.
- `testLanguagePrefixIsCaseInsensitive`: `en-US` accepts `EN` and rejects `fr`.
- `testNamespacePointerAndNamespaceIteratorExist`: namespace accessors return objects for a configured element.
