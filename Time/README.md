# Time (joda-time)

Defects4J มี active bugs 26 รายการในโครงงานนี้ ดู `bug-index.csv` สำหรับรหัสบั๊กทั้งหมด โฟลเดอร์ SA/BPSO/ChatGPT/Gemini เป็นโครงสร้างเตรียมงาน ยังไม่มีผลทดสอบของโปรเจกต์นี้

เมื่อทดลอง ให้สร้างโฟลเดอร์ `Time-<id>` ใต้ Test, TestCode, Prompt, Result หรือ Result_Round1/2 ตามวิธี แล้วเก็บข้อมูล buggy/fixed, coverage, เวลา, configuration และ log ที่วัดจริง
