## 2. TEST CASE DESIGN

- `testRootSeparatorDefaultAndNull`: default separator then null; source writes the default space and emits nothing for null.
- `testRootSeparatorReplacement`: configured `||`; source writes the configured serialized string.
- `testRootSeparatorEqualValueReturnsSamePrinter`: equal serialized value; source returns this when values are equal.
- `testArrayIndentersSetToNullAndWriteArray`: null indenter and empty array; null maps to no-op, while empty end writes a space.
- `testObjectIndentersSetToNullAndWriteObject`: null indenter and empty object; null maps to no-op, while empty end writes a space.
- `testArrayIndenterMutantAndIdentity`: same indenter preserves instance; null maps to no-op and changes the default array indenter.
- `testObjectIndenterMutantAndIdentity`: explicit no-op changes the default; null then resolves to the same no-op.
- `testSpacesMutantsAndIdentity`: default spaces preserve instance; disabling creates a copy and repeated disabling preserves it.
- `testCustomSeparatorsWithSpaces`: separators `:`, `;`, `|`; source adds surrounding spaces only to the field separator.
- `testCustomSeparatorsWithoutSpaces`: custom `=` separator with spaces disabled; source emits the separator alone.
- `testCreateInstanceIsSeparate`: ordinary printer; source creates a new copy.
- `testStartObjectAndEmptyEnd`: empty default object; braces with the empty-object interior space.

- `testStartArrayAndEmptyEnd`: empty default array; brackets with the empty-array interior space.

- `testNopIndenter`: level zero; source writes nothing and reports inline.
