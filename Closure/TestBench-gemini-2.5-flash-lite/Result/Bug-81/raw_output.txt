    private Config getConfig() {
        // Using default values for config as they are not critical for the AST transformation logic being tested.

    private ErrorReporter getErrorReporter() {
        // A simple mock ErrorReporter that does nothing.
        return new ErrorReporter() {
            @Override
            public void warning(String message, String sourceName, int line, String lineSource, Object[] formatArgs) { }
            @Override
            public void error(String message, String sourceName, int line, String lineSource, Object[] formatArgs) {
                // In a real test, you might want to assert that errors are reported.
                // For this task, we assume valid inputs that don't trigger errors in the reference.
            }
            @Override
            public com.google.javascript.jscomp.mozilla.rhino.EvaluatorException runtimeError(String message, String sourceName, int line, String lineSource, int index, Object[] formatArgs) {
                return new com.google.javascript.jscomp.mozilla.rhino.EvaluatorException(message);
            }
        };
    }

    private AstRoot createAstRoot(AstNode... nodes) {
        AstRoot root = new AstRoot();
        for (AstNode node : nodes) {
            root.addChildToBack(node);
        }
        root.setSourceName("test"); // Default source name
        return root;
    }

        Node objNode = exprResultNode.getFirstChild();

        assertEquals(2, objNode.getChildCount());

        Node prop1 = objNode.getFirstChild();
        assertEquals(Token.STRING, prop1.getType());
        assertEquals("a", prop1.getString());
        assertEquals(Token.NUMBER, prop1.getFirstChild().getType());
        assertEquals(1.0, prop1.getFirstChild().getDouble(), 0.0);

        Node prop2 = objNode.getLastChild();
        assertEquals(Token.STRING, prop2.getType());
        assertEquals("b", prop2.getString());
        assertTrue(prop2.getBooleanProp(Node.QUOTED_PROP)); // Key "b" should be quoted
        assertEquals(Token.STRING, prop2.getFirstChild().getType());
        assertEquals("c", prop2.getFirstChild().getString());
    }

**1. SOURCE CODE ANALYSIS**
The tests focus on the `IRFactory.transformTree` static method. They cover various AST node types like expressions, statements, loops, and control flow structures, ensuring their transformation into the IR `Node` representation. The tests also cover directive parsing and JsDoc handling.

**2. TEST CASE DESIGN**
- `testTransformTree_EmptyAstRoot`: Input: Empty `AstRoot`. Expected: `SCRIPT` node with no children. Derivation: `transform(node)` on an empty `AstRoot` creates an empty `SCRIPT` node.
- `testTransformTree_SingleExpressionStatement`: Input: `AstRoot` with one `ExpressionStatement`. Expected: `SCRIPT` -> `EXPR_RESULT` -> `STRING`. Derivation: `transform(ExpressionStatement)` produces `EXPR_RESULT`, `transform(StringLiteral)` produces `STRING`.
- `testTransformTree_VariableDeclaration`: Input: `AstRoot` with `VariableDeclaration`. Expected: `SCRIPT` -> `VAR` -> `NAME` with initializer. Derivation: `transform(VariableDeclaration)` maps to `VAR`, `transform(VariableInitializer)` maps to `NAME` with child for initializer.
- `testTransformTree_IfStatement`: Input: `AstRoot` with `IfStatement`. Expected: `SCRIPT` -> `IF` -> condition, then-branch. Derivation: `transform(IfStatement)` maps to `IF` with transformed condition and then-part.
- `testTransformTree_IfElseStatement`: Input: `AstRoot` with `IfStatement` and `elsePart`. Expected: `SCRIPT` -> `IF` -> condition, then-branch, else-branch. Derivation: `transform(IfStatement)` maps to `IF` with all three children transformed.
- `testTransformTree_WhileLoop`: Input: `AstRoot` with `WhileLoop`. Expected: `SCRIPT` -> `WHILE` -> condition, body. Derivation: `transform(WhileLoop)` maps to `WHILE` with transformed condition and body.
- `testTransformTree_DoLoop`: Input: `AstRoot` with `DoLoop`. Expected: `SCRIPT` -> `DO` -> body, condition. Derivation: `transform(DoLoop)` maps to `DO` with transformed body and condition.
- `testTransformTree_ForLoop`: Input: `AstRoot` with `ForLoop`. Expected: `SCRIPT` -> `FOR` -> initializer, condition, increment, body. Derivation: `transform(ForLoop)` maps to `FOR` with all four children transformed.
- `testTransformTree_ForInLoop`: Input: `AstRoot` with `ForInLoop`. Expected: `SCRIPT` -> `FOR` -> iterator, iteratedObject, body. Derivation: `transform(ForInLoop)` maps to `FOR` with transformed iterator, object, and body.
- `testTransformTree_FunctionDeclaration`: Input: `AstRoot` with `FunctionNode`. Expected: `SCRIPT` -> `FUNCTION` -> name, params, body. Derivation: `transform(FunctionNode)` maps to `FUNCTION` with its components transformed.
- `testTransformTree_FunctionExpression`: Input: `AstRoot` with `ExpressionStatement` containing `FunctionNode`. Expected: `SCRIPT` -> `EXPR_RESULT` -> `FUNCTION` -> (empty name), params, body. Derivation: Handles anonymous function expressions correctly.
- `testTransformTree_ObjectLiteral`: Input: `AstRoot` with `ExpressionStatement` containing `ObjectLiteral`. Expected: `SCRIPT` -> `EXPR_RESULT` -> `OBJECTLIT` -> properties. Derivation: `transform(ObjectLiteral)` maps to `OBJECTLIT` with its elements transformed.
- `testTransformTree_ArrayLiteral`: Input: `AstRoot` with `ExpressionStatement` containing `ArrayLiteral`. Expected: `SCRIPT` -> `EXPR_RESULT` -> `ARRAYLIT` -> elements. Derivation: `transform(ArrayLiteral)` maps to `ARRAYLIT` with its elements transformed.
- `testTransformTree_BinaryExpression`: Input: `AstRoot` with `ExpressionStatement` containing `InfixExpression` (ADD). Expected: `SCRIPT` -> `EXPR_RESULT` -> `ADD` -> left, right. Derivation: `transform(InfixExpression)` maps to the corresponding operator token.
- `testTransformTree_UnaryExpression`: Input: `AstRoot` with `ExpressionStatement` containing `UnaryExpression` (NEG). Expected: `SCRIPT` -> `EXPR_RESULT` -> `NEG` -> operand. Derivation: `transform(UnaryExpression)` maps to the unary operator token.
- `testTransformTree_UnaryExpressionNegationResult`: Input: Unary negation expression. Expected: The number node itself is modified to hold the negated value. Derivation: Specific handling for `Token.NEG` negates the operand's double value.
