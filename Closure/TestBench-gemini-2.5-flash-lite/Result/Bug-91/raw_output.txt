**SOURCE CODE ANALYSIS**
The `CheckGlobalThis` class checks for the unsafe use of the `this` keyword. It uses `shouldTraverse` to avoid traversing into safe contexts (constructors, `@this` annotated functions, prototype methods) and `visit` to report `GLOBAL_THIS` diagnostic when an unsafe `this` is encountered. The `shouldReportThis` method determines if a `this` node should be reported based on its parent (assignment LHS, property access).

**TEST CASE DESIGN**
- `testThisInGlobalScope`: Input: `this` in global scope. Expected: Report `GLOBAL_THIS`. Derivation: `this` in `SCRIPT` context, not within any safe function.
- `testThisInFunctionNotConstructor`: Input: `this` inside a normal function. Expected: No report. Derivation: `shouldTraverse` returns false for functions unless they meet specific criteria; here it's a simple function, so it should be traversed, but it's not an assignment LHS or property access.
- `testThisInConstructor`: Input: `this` inside a function annotated with `@constructor`. Expected: No report. Derivation: `shouldTraverse` returns false for constructor functions.
- `testThisWithConstructorAnnotation`: Input: `this` inside a function with `@this` annotation. Expected: No report. Derivation: `shouldTraverse` returns false for functions with `@this` annotation.
- `testThisInObjectLiteralMethod`: Input: `this` inside an object literal method. Expected: No report. Derivation: Object literal methods are generally considered safe contexts for `this`.
- `testThisInAssignLhs`: Input: `this` as the left-hand side of an assignment. Expected: Report `GLOBAL_THIS`. Derivation: `shouldReportThis` returns true when `assignLhsChild` is not null.
- `testThisInAssignLhsWithPropertyAccess`: Input: `this.prop` as the left-hand side of an assignment. Expected: Report `GLOBAL_THIS`. Derivation: `shouldReportThis` returns true when `assignLhsChild` is not null, and `this` is part of the LHS.
- `testThisInPropertyAccess`: Input: `this.prop`. Expected: Report `GLOBAL_THIS`. Derivation: `shouldReportThis` returns true when parent is `GETPROP`.
- `testThisNotInPropertyAccess`: Input: `func(this)`. Expected: No report. Derivation: Parent is `CALL`, not `GETPROP`.
- `testThisInPrototypeMethod`: Input: `this` inside a function assigned to `prototype`. Expected: No report. Derivation: `shouldTraverse` returns false for functions lent to a prototype.
- `testThisInFunctionWithInterfaceAnnotation`: Input: `this` in a function annotated with `@interface`. Expected: No report. Derivation: `shouldTraverse` returns false for interface functions.
- `testThisInFunctionWithOverrideAnnotation`: Input: `this` in a function annotated with `@override`. Expected: No report. Derivation: `shouldTraverse` returns false for overridden functions.
- `testThisInFunctionAssignedToProperty`: Input: `obj.method = function() { this }`. Expected: No report. Derivation: The function itself is traversed, but `this` is not on assignment LHS or property access.
- `testThisInVarDeclaration`: Input: `var x = function() { this }`. Expected: No report. Derivation: Similar to previous, `this` is in a safe function context and not directly causing a report.
- `testThisInAssignmentToPrototypeProperty`: Input: `prototype.method = this`. Expected: No report. Derivation: `shouldTraverse` prevents traversal into assignments to prototype properties.
- `testThisInAssignmentToSubPropertyOfPrototype`: Input: `prototype.sub.method = this`. Expected: No report. Derivation: `shouldTraverse` prevents traversal into assignments to prototype properties.
- `testThisInFunctionWithNoLogicalPlaceForAnnotation`: Input: `1 + function() { this }`. Expected: Report `GLOBAL_THIS`. Derivation: `shouldTraverse` determines there's no logical place for a `@this` annotation.
- `testThisInFunctionWithLendsAnnotation`: Input: `method: function() { this }` with `@lends MyObject.prototype`. Expected: No report. Derivation: `shouldTraverse` checks for `@lends` on prototype.
- `testThisOnLeftOfAssignWithPropertyAccess`: Input: `this.prop = 1`. Expected: Report `GLOBAL_THIS`. Derivation: `shouldReportThis` returns true for assignment LHS.
- `testThisOnLeftOfAssignWithNestedPropertyAccess`: Input: `this.inner.outer = 1`. Expected: Report `GLOBAL_THIS`. Derivation: `shouldReportThis` returns true for assignment LHS.
- `testThisInSimpleAssignment`: Input: `x = this`. Expected: No report. Derivation: `this` is on the right side of an assignment.
- `testThisInAssignmentWithParentBlock`: Input: `function() { x = this }`. Expected: No report. Derivation: `this` on right side of assignment.
- `testThisInAssignLhsThenReset`: Input: `assignLhsChild` is set, then reset. Expected: Correct handling of `assignLhsChild` state. Derivation: Tests state management of `assignLhsChild`.
