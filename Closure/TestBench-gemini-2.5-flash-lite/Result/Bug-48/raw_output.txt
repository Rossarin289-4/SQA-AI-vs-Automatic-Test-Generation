1. SOURCE CODE ANALYSIS - The `TypedScopeCreator` class is responsible for building scopes with type information. The tests focus on `createScope`, `visit`, and `shouldTraverse` methods, covering variable declarations (var, const), function declarations and expressions, native types, object literals, qualified names, enums, typedefs, constructors, interfaces, methods, catch clauses, and type annotations from JSDoc.
2. TEST CASE DESIGN -
    - `testGlobalScopeCreation`: Input: "var a = 1;", Expected: Scope with 'a' declared. Derivation: Direct declaration in global scope.
    - `testLocalScopeCreation`: Input: "function f() { var a = 1; }", Expected: Function scope with 'a' declared, global scope without 'a'. Derivation: Lexical scoping rules.
    - `testVarDeclaration`: Input: "var x;", Expected: 'x' declared, type inferred. Derivation: Standard var declaration.
    - `testConstDeclaration`: Input: "const y = 5;", Expected: 'y' declared, type is NUMBER. Derivation: const declaration with literal.
    - `testFunctionDeclaration`: Input: "function foo() {}", Expected: 'foo' declared, type is FUNCTION. Derivation: Standard function declaration.
    - `testFunctionExpressionDeclaration`: Input: "var bar = function() {};", Expected: 'bar' declared, type is FUNCTION. Derivation: Function expression assigned to var.
    - `testGlobalThisDeclaration`: Input: "var globalVar = 1;", Expected: 'globalVar' declared on globalThis. Derivation: Global variables are properties of globalThis.
    - `testUndefinedDeclaration`: Input: "var u = undefined;", Expected: 'u' declared, type is VOID. Derivation: Use of undefined keyword.
    - `testNativeTypes`: Input: "var s = 'hello'; var n = 123; var b = true;", Expected: Correct native types (STRING, NUMBER, BOOLEAN). Derivation: Literal type inference.
    - `testObjectLiteral`: Input: "var obj = {a: 1, b: 'str'};", Expected: 'obj' type has properties 'a' (NUMBER) and 'b' (STRING). Derivation: Object literal property typing.
    - `testQualifiedNameDeclaration`: Input: "var ns; ns.prop = 1;", Expected: 'ns' declared (UNKNOWN/OBJECT), 'prop' declared on 'ns' (NUMBER). Derivation: Property assignment to undeclared qualified name.
    - `testQualifiedNameDeclarationWithExistingType`: Input: "var obj = {}; obj.prop = 1;", Expected: 'obj' is OBJECT, 'prop' declared on 'obj' (NUMBER). Derivation: Property assignment to existing object.
    - `testEnumDeclaration`: Input: "/** @enum {number} */ var Color = { RED: 1, GREEN: 2 };", Expected: 'Color' is ENUM(NUMBER), properties RED/GREEN exist. Derivation: @enum annotation.
    - `testTypedefDeclaration`: Input: "/** @typedef {number} MyNumber;", Expected: 'MyNumber' alias for NUMBER. Derivation: @typedef annotation.
    - `testConstructorDeclaration`: Input: "/** @constructor */ function MyClass() {}", Expected: 'MyClass' is CONSTRUCTOR, 'instance' is MyClass type. Derivation: @constructor annotation.
    - `testInterfaceDeclaration`: Input: "/** @interface */ function MyInterface() {}", Expected: 'MyInterface' is INTERFACE. Derivation: @interface annotation.
