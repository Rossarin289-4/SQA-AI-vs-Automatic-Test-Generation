    // Helper method to create an AstRoot from a source string
    private AstRoot createAstRoot(String source) {
        // This is a simplified way to create an AstRoot. In a real scenario,
        // a proper parser would be used. For testing purposes, we assume a basic structure.
        AstRoot root = new AstRoot();
        root.setSource(source);
        // Add a dummy node to represent the script content
        root.addChildToBack(new Block());
        return root;
    }

        assertEquals(1, directives.size());

        assertEquals(Token.FUNCTION, irNode.getChildAtIndex(0).getType());

## SOURCE CODE ANALYSIS
The tests cover the `transformTree` method of the `IRFactory` class, transforming various AST nodes like expressions, statements, loops, declarations, and literals into their corresponding IR nodes. It specifically tests edge cases like directives, string literals with special characters, and const declarations with different configurations.

## TEST CASE DESIGN
- testTransformTree_emptyScript: Input: "", Expected: SCRIPT node with no children. Derived from IRFactory.transformTree with empty AstRoot.
- testTransformTree_singleExpression: Input: "1 + 2;", Expected: SCRIPT -> EXPR_RESULT -> ADD node. Derived from IRFactory.transformTree.
