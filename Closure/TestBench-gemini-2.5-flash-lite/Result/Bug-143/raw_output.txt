1. SOURCE CODE ANALYSIS - The `RemoveConstantExpressions` pass traverses the AST. For `EXPR_RESULT` nodes, it checks if the expression has side effects. If not, it replaces the `EXPR_RESULT` with nodes that *do* have side effects (or nothing if there are none). Tests focus on various expression types within `EXPR_RESULT` statements and their expected simplification.
2. TEST CASE DESIGN -
    - `testProcess_simpleExpression`: Input: `1;`. Expected: empty block. Derived: `NodeUtil.nodeTypeMayHaveSideEffects(Node.newNumber(1))` is false.
    - `testProcess_expressionWithSideEffect`: Input: `foo();`. Expected: `foo();`. Derived: `NodeUtil.nodeTypeMayHaveSideEffects(Node.newCall(Node.newString("foo")))` is true.
    - `testProcess_expressionWithSideEffectAndConstant`: Input: `1 + foo()`. Expected: `foo();`. Derived: `1` has no side effects, `foo()` does.
    - `testProcess_multipleExpressions`: Input: `1; bar(); 2;`. Expected: `bar();`. Derived: Constants removed, side-effecting call preserved.
    - `testProcess_expressionWithNew`: Input: `new Object();`. Expected: `new Object();`. Derived: `NEW` has side effects.
    - `testProcess_nestedExpressionsWithSideEffects`: Input: `1 + foo() + bar()`. Expected: `foo(); bar();`. Derived: Constants removed, calls preserved and become separate statements.
    - `testProcess_nestedExpressionsConstantAtEnd`: Input: `foo() + 1`. Expected: `foo();`. Derived: Constant removed.
    - `testProcess_expressionWithOnlyConstant`: Input: `10;`. Expected: empty block. Derived: Constant-only expression removed.
    - `testProcess_complexExpressionWithSideEffectsAndConstants`: Input: `1 + foo() + 2 + bar() + 3`. Expected: `foo(); bar();`. Derived: Constants removed, calls preserved.
    - `testProcess_noExpressionStatements`: Input: `var x = 1;`. Expected: `var x = 1;`. Derived: No `EXPR_RESULT` to process.
    - `testProcess_functionCallAsExpressionStatement`: Input: `myFunc();`. Expected: `myFunc();`. Derived: Call has side effects.
    - `testProcess_newExpressionAsExpressionStatement`: Input: `new MyClass();`. Expected: `new MyClass();`. Derived: `NEW` has side effects.
    - `testProcess_assignmentAsExpressionStatement`: Input: `x = 1;`. Expected: `x = 1;`. Derived: Assignment has side effects.
