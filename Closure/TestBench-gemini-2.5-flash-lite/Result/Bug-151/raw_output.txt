- `testBooleanOptionHandler_parseArguments_falseValues`: Tests parsing "false", "off", "no", "0" as false.
- `testBooleanOptionHandler_parseArguments_noValue`: Tests default true value when no parameter is provided.
- `testBooleanOptionHandler_parseArguments_invalidValue`: Tests exception handling for invalid boolean values.
- `testFormattingOption_applyToOptions_prettyPrint`: Verifies that `PRETTY_PRINT` sets `options.prettyPrint`.
- `testFormattingOption_applyToOptions_printInputDelimiter`: Verifies that `PRINT_INPUT_DELIMITER` sets `options.printInputDelimiter`.

- `testConstructor_withHelpArg`: Tests constructor with `--help` flag results in invalid configuration.
- `testConstructor_withVersionArg`: Tests constructor with `--version` flag (expected to print version and invalidate config).
