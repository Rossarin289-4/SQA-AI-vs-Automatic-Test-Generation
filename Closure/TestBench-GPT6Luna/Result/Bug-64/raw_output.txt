2. TEST CASE DESIGN  
- `testAcceptsEs5`: ECMASCRIPT5 input mode; expects true from `acceptEcmaScript5`’s switch cases.
- `testRejectsEs3`: ECMASCRIPT3 input mode; expects false because the switch accepts only the two ES5 modes.
- `testLanguageModeReflectsOptions`: strict ES5 mode; expects the selected language mode.
- `testTypeCheckingOption`: enabled type-checking flag; expects true from the options field.
- `testIdeModeOption`: IDE mode enabled; expects true from the options field.
- `testConstKeywordOption`: const keyword enabled; expects true from the options field.
- `testErrorManagerInitiallyAvailable`: fresh compiler; expects a non-null manager because the getter initializes options and its manager.
- `testEmptyCompileInputSource`: empty source; expects a result and zero errors for valid empty JavaScript.
- `testParseSourceAndPrint`: parses `var x=1;`; expects the printer’s normalized source `var x=1`.
- `testToSourceArrayHasInputForInitializedCompiler`: one configured input; expects an array of length one.
- `testGetSourceLineValidAndBoundaryNumbers`: line indices 1, 2, 0, and 3; expects the corresponding lines and null outside the valid range.
- `testGetSourceLineUnknownName`: unknown source; expects null from name lookup.
- `testGetInputByInitializedName`: configured input and missing name; expects a registered input and null.
- `testRebuildInputsFromModules`: one module containing one input; expects that input to be available by name after rebuild.
- `testNewExternInputIsRegistered`: adds an extern; expects the returned input to be the registered instance.
- `testNewExternInputRejectsDuplicateName`: repeats an extern name; expects `IllegalArgumentException` from the explicit conflict check.
- `testDisableThreadsStillCompiles`: disables threads before compiling valid empty source; expects a result and zero errors.
- `testNoErrorsForValidCompilation`: valid declaration; expects no errors.
- `testInvalidSourceHasErrors`: malformed declaration; expects compilation errors and a positive error count.
- `testGetAstDotGraphWithoutParsedTree`: no AST exists; expects the documented empty-string branch.
- `testRootAvailableAfterCompilation`: after compilation; expects the created AST root.
- `testErrorManagerCanBeReplaced`: installs a manager; expects the getter to return the same manager.
- `testErrorManagerRejectsNull`: null manager; expects `NullPointerException` from `checkNotNull`.
