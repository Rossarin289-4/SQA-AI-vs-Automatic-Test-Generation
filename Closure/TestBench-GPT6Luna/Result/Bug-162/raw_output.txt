### 2. TEST CASE DESIGN
- `testArgumentsVarIsCachedAndHasNoDeclaration`: create a bottom scope; repeated arguments lookup returns the same `arguments` Var with no node or declaration and index -1.
- `testArgumentsVarIsNotInDeclaredVariables`: requesting arguments does not add it to the declared map; count is 0 and it is not declared.
- `testGlobalScopePropertiesAndRoot`: bottom-scope constructor yields the supplied root, no parent, and global state.
- `testBottomScopeRecordsBottomState`: bottom-scope constructor marks it bottom and starts with zero variables.
- `testChildScopeHasParentAndLocalState`: child construction links its parent/root and marks it local, non-global, and non-bottom.
- `testGetVarAndOwnSlotDistinguishParentDeclaration`: a child lookup resolves its parent's variable, while own-slot lookup does not.
- `testOwnDeclarationAndMissingNameLookups`: own declaration is found by slot and name; absent names return null.
- `testIsDeclaredCanLimitSearchToCurrentScope`: recursive lookup finds the parent's variable, nonrecursive lookup does not, and missing lookup is false.
- `testDeclaredVarsRemainInInsertionOrder`: two declarations are returned in insertion order and counted.
- `testAllSymbolsAndReferencesContainDeclaredVariable`: symbol and reference iteration each contain the declared Var once; its scope is the declaring scope.
- `testVarIdentityUsesItsNameNode`: Var node access, symbol/declaration, and name reflect the declaration input.
- `testVarWithoutTypeHasInferredStateAndStableString`: inferred declaration with null type reports inferred and formats the source-defined string.
- `testNonInferredDeclarationReportsDeclaredTypeState`: explicit `false` inference flag is preserved; absent type, define, and no-shadow info produce the asserted values.
- `testInitialValueOfVarWithoutInitializerIsNull`: a bare VAR name has no initializer and its parent is the VAR node.
- `testInitialValueOfVarWithInitializerIsFirstChild`: VAR declaration's first child is returned as its initializer.
- `testInitialValueOfAssignmentIsLastChild`: ASSIGN declaration returns its RHS as the initial value.
- `testInitialValueForFunctionParentIsFunctionNode`: FUNCTION parent is returned directly.
- `testDeclarativelyUnboundFilterIncludesUntypedVarDeclaration`: untyped, non-extern VAR declaration meets every filter condition and appears once.
- `testDeclarativelyUnboundFilterExcludesTypedVarDeclaration`: typed declarations are not constructible from the permitted API in this test setup; this test instead duplicates an untyped setup and is not a reliable typed-branch check.
