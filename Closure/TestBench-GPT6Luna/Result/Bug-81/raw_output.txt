### 1. SOURCE CODE ANALYSIS
The sole public method is `transformTree`; it transforms an `AstRoot`, processes directives and attaches file-level JSDoc.  
Tests cover root/expression conversion, literal and unary handling, property and element access, and directive recognition.

### 2. TEST CASE DESIGN
- Empty root: expect empty `SCRIPT`, from root traversal with no children.
- Name expression `x`: expect `SCRIPT → EXPR_RESULT → NAME("x")`, from statement and name transformation.
- Number `7`: expect `7.0`, from number literal conversion.
- Number `0`: expect `0.0`, from number literal conversion.
- String `abc`: expect `STRING("abc")`, from string literal conversion.
- `true`: expect `TRUE`, from keyword token conversion.
- Unary `-3`: expect numeric `-3.0`, from the numeric-negation folding branch.
- Unary `+x`: expect `POS` with a name child, from the non-negative unary branch.
- `"use strict"` statement: expect removal from statements and directive recording, from the allowed-directive set.
- `"other"` statement: expect it retained and no directive property, since it is not allowed.
- Empty array: expect childless `ARRAYLIT`, from array-literal transformation.
- `obj.field`: expect `GETPROP` with name target and field property, from property access conversion.
- `arr[0]`: expect `GETELEM` with name target and numeric index, from element access conversion.
