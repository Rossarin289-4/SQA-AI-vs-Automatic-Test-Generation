### 1. SOURCE CODE ANALYSIS
Covered line-offset calculation and bounds, line lookup and its cached-offset behavior, and region start/end/excerpt handling.
Also tested code-loading factories, generated-code caching, original-path behavior, name, extern status, and cache clearing.

### 2. TEST CASE DESIGN
- `testNameAndStringRepresentation`: name `unit.js`; both methods return the stored filename.
- `testCodeFactoryAndReader`: code `abc`; reader yields its characters then EOF.
- `testOriginalPathDefaultsToName`: no override; getter falls back to filename.
- `testOriginalPathCanBeSet`: path `origin.js`; getter returns the stored override.
- `testOriginalPathCanBeResetToName`: set then null; getter falls back to filename.
- `testExternDefaultsToFalse`: newly created source; initializer sets false.
- `testGetLineOffsetForLines`: `ab\ncde\nf`; offsets accumulate prior line lengths plus newline.
- `testGetLineOffsetRejectsZero`: line 0 is below the valid 1-based range.
- `testGetLineOffsetRejectsFirstPastEnd`: line 3 exceeds the two-line source.
- `testGetLineForFirstMiddleAndLastLines`: three-line source; each result is its line without newline.
- `testGetLineForTrailingNewline`: final newline leaves no content at line 2, so lookup is null.
- `testGetLineForMissingLine`: line 3 is beyond the two available lines.
- `testGetLineLookupCanMoveBackwards`: searching line 3 then line 1 returns each matching line.
- `testRegionCenteredAndTruncatedAtEnd`: line 4 in seven lines yields lines 2–7 and their joined excerpt.
- `testRegionAtBeginning`: line 1 starts at line 1 and extends through the available six lines.
- `testRegionDoesNotExistPastAvailableLines`: requested line 3 is beyond the two-line source.
- `testReaderFactory`: reader contains `read`; factory materializes that text.
- `testInputStreamFactoryReadsUtf8`: UTF-8 bytes decode to `café`.
- `testGeneratorProvidesCode`: generator returns `generated`; source returns its generated text.
- `testGeneratorCodeIsCachedAndClearRegenerates`: successive generator outputs show caching, then regeneration after clearing.
- `testClearCachedSourcePreservesPreloadedCode`: base implementation does not clear preloaded code.
- `testFromCodeWithExplicitOriginalPath`: explicit original path is retained with the given name and code.
- `testConstructionRejectsEmptyName`: empty filename triggers the constructor’s argument check.
- `testGetCodeReaderAtEnd`: empty source reader immediately returns EOF.
