    public void testCollapsesRepeatedName() throws Exception {
        Node script = new Node(Token.SCRIPT);
        Node first = new Node(Token.EXPR_RESULT,
                new Node(Token.ASSIGN, Node.newString(Token.NAME, "x"), Node.newString(Token.NAME, "y")));
        Node second = new Node(Token.EXPR_RESULT, Node.newString(Token.NAME, "x"));
        script.addChildToBack(first);
        script.addChildToBack(second);

        new ExploitAssigns().optimizeSubtree(script);

        assertSame(first, script.getFirstChild());
        assertSame(second.getFirstChild(), first.getFirstChild());
        assertEquals(Token.ASSIGN, first.getFirstChild().getType());
    }

Tests exercise repeated name and immutable-value replacement, nested assignments, safe and blocked property cases, and traversal through control-flow and variable nodes.

### 2. TEST CASE DESIGN
- `testCollapsesRepeatedName`: `x = y; x` — the second use is replaced by the first assignment.
- `testDoesNotCollapseDifferentName`: `x = y; z` — names differ, so `z` remains.
- `testCollapsesRepeatedNumberLiteral`: `x = 7; 7` — equal immutable number is replaced by the assignment.
- `testDoesNotCollapseDifferentNumberLiteral`: `x = 7; 8` — unequal literals do not match.
- `testCollapsesRepeatedBooleanLiteral`: `x = true; true` — equal immutable boolean is replaced.
- `testDoesNotCollapseDifferentBooleanLiteral`: `x = true; false` — unequal boolean remains.
- `testCollapsesNameUsedInVarInitializer`: `x = y; var z = x` — traversal descends into the initialized variable.
- `testDoesNotCollapseIntoUninitializedVar`: `x = y; var z` — the variable has no initializer.
- `testCollapsesThroughReturn`: `x = y; return x` — traversal descends through `RETURN`.
- `testCollapsesThroughAndLeftSide`: `x = y; x && z` — traversal descends through `AND` to its first child.
- `testDoesNotCollapseIntoCallExpression`: a call follows the assignment — it is not a matching immutable value.
- `testCollapsesAssignmentOnRightSide`: `x = 3; y = 3` — the matching immutable right-hand value is replaced.
- `testDoesNotCollapseGetpropOnArbitraryObject`: `obj.p = 3; obj.p` — a property lvalue on a non-`this` object is not collapsible.
- `testCollapsesThisGetprop`: `this.p = 3; this.p` — a `this` property is eligible and the repeated property is replaced.
- `testCollapsesNestedAssignmentToRepeatedName`: `a = (x = 3); x` — the nested assignment is processed.
- `testPreservesEmptyScript`: empty script — optimization returns the input node and leaves it empty.
