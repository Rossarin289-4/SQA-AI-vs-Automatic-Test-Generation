1. SOURCE CODE ANALYSIS - The tests focus on `ExternalTypeHandler` and its nested `Builder` class. Key methods tested include `start()`, `handleTypePropertyValue()`, `handlePropertyValue()`, `complete()`, `Builder.addExternal()`, and `Builder.build()`. 2. TEST CASE DESIGN -
    - `testStartReturnsNewInstance`: Checks that `start()` returns a distinct instance.
    - `testHandleTypePropertyValue_propertyNotFound`: Ensures `false` is returned when property name is not in the index.
    - `testHandleTypePropertyValue_typePropertyNotFound`: Ensures `false` is returned when property name does not match the type property name.
    - `testHandleTypePropertyValue_setsTypeIdAndTriggersDeserializeWhenPossible`: Verifies type ID is set and deserialization is triggered when token is buffered.
    - `testHandlePropertyValue_propertyNotFound`: Ensures `false` is returned when property name is not in the index.
    - `testHandlePropertyValue_buffersTokenAndTypeId`: Checks that token is buffered and type ID is not yet set.
    - `testHandlePropertyValue_triggersDeserializeWhenPossible`: Verifies deserialization is triggered when type ID and token are available.
    - `testComplete_handlesMissingTypeIdAndToken`: Checks that `complete()` handles cases where both type ID and token are missing.

    - `testComplete_throwsExceptionWhenTokenMissingButTypeIdPresent`: Verifies `JsonMappingException` is thrown when token is missing but type ID is present.
    - `testComplete_handlesNaturalTypes`: Tests handling of natural types when only a token buffer is present.
