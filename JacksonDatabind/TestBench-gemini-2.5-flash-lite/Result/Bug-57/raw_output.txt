1. SOURCE CODE ANALYSIS - This test class focuses on testing the various builder methods (`with`, `without`, `forType`, etc.) of `ObjectReader` which create new, immutable reader instances with modified configurations. It also tests several `readValue` and `readTree` methods that handle different input sources (Parser, InputStream, Reader, String, byte array, File, URL, JsonNode) and different reading modes (single value, multiple values, tree).
2. TEST CASE DESIGN -
    - testDefaultConstructor: Verifies a newly created ObjectReader has expected default configurations.
    - testWithDeserializationFeatureEnabled: Tests enabling a single DeserializationFeature.
    - testWithDeserializationFeaturesEnabled: Tests enabling multiple DeserializationFeatures.
    - testWithFeaturesEnabled: Tests enabling multiple DeserializationFeatures using the varargs version.
    - testWithoutDeserializationFeature: Tests disabling a single DeserializationFeature.
    - testWithoutDeserializationFeatures: Tests disabling multiple DeserializationFeatures.
    - testWithoutFeatures: Tests disabling multiple DeserializationFeatures using the varargs version.
