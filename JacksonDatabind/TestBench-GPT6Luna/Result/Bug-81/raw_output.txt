### 2. TEST CASE DESIGN
- `testEnumExplicitNameAndFallback`: annotated names and an empty/unannotated annotation value; expects explicit nonempty name or enum constant name.
- `testEnumValuesUpdatesOnlyNonEmptyExplicitName`: three initial names; only the nonempty explicit enum annotation replaces an entry.
- `testRootNameAndNamespace`: annotated class; reads its explicit root name and namespace.
- `testUnannotatedRootNameIsNull`: plain class; source returns null without `JsonRootName`.
- `testFilterId`: nonempty filter ID; source returns the annotation value.
- `testClassDescription`: annotated class; source returns its description value.
- `testPropertyNameIndexDefaultAndRequired`: required property with index zero and default; values come directly from `JsonProperty`.
- `testUnknownPropertyIndexAndEmptyDefaultAreNull`: index one is retained; omitted default and required marker produce null.
- `testAliasesAndIgnoreMarker`: two aliases are constructed in order; `JsonIgnore` true marks the field ignored.
- `testDescriptionAccessFormatAndViews`: checks description, access mode, format shape, and the declared view class.
- `testNameForSerializationAndDeserializationPrecedence`: getter and setter annotations each supply their configured name.
- `testAsValueAndAnyGetterMarkers`: enabled annotations yield true through modern and deprecated marker methods.
- `testTypeIdAndUnwrappingTransformer`: `JsonTypeId` yields true; configured prefix/suffix transform and reverse the sample name.
- `testIncludeAndSerializationTypingDefaults`: absent inclusion uses `USE_DEFAULTS`; absent `JsonSerialize` yields null typing and serializer.
- `testSetConstructorPropertiesFlagIsFluent`: setter returns the same introspector instance.
