## 2. TEST CASE DESIGN

- Unresolved construction: reference is null and string ends in `UNRESOLVED`, directly from the null branch.
- Resolved rendering: stores a String-raw-class reference; rendering appends its raw class name.
- Reassignment: setting a second reference throws `IllegalStateException`; first reference remains set.
- Unresolved equality: distinct unresolved instances compare false; self-comparison is true.
- Resolved equality: references with equal recursive types compare equal.
- Null and other-class equality: both comparisons are false by the equality guards.
- Concrete-class equality: a different `TypeBase` implementation is rejected by the exact-class check.
- Container status, unresolved and resolved: implementation always returns false.
- Content type, type handler, content handler, value handler, content value handler, and static typing: each method returns `this`.
- Refinement: implementation returns null.
- Erased and generic signatures: each delegates to the reference and returns the supplied builder.
- Superclass delegation: result is the reference's superclass.
- Unresolved Object superclass: constructor's superclass is null and unresolved path uses it.
