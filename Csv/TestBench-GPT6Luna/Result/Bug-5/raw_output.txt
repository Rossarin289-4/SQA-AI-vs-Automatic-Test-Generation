## 2. TEST CASE DESIGN
- `testGetOutReturnsSuppliedAppendable`: supplied builder; same reference, directly returned by `getOut()`.
- `testPrintPlainValue`: `"abc"`; unchanged when no quoting is needed.
- `testPrintSeparatesValues`: `"a"`, then `"b"`; delimiter inserted after the first value.
- `testPrintNullAsEmptyByDefault`: null; source substitutes the empty string when no null string is configured.
- `testPrintNullUsingConfiguredNullString`: null with `"NA"` configured; source uses that string.
- `testPrintQuotesDelimiter`: `"a,b"`; delimiter triggers minimal quoting.
- `testPrintDoublesEmbeddedQuote`: `a"b`; embedded quote is doubled inside enclosing quotes.
- `testPrintQuotesEmptyFirstValue`: empty first token; source quotes it to preserve an empty field.
- `testPrintQuotesValueEndingInSpace`: `"a "`; trailing space triggers minimal quoting.
- `testPrintQuotePolicyAll`: `"abc"`; `ALL` quotes every value.
- `testPrintQuotePolicyNonNumeric`: string and integer `12`; source quotes non-`Number` and leaves `Number` unquoted.
- `testPrintQuotePolicyNoneEscapesDelimiter`: `"a,b"`; `NONE` uses escape processing for the delimiter.
- `testPrintRecordIterableAndRecordSeparator`: two values; delimiter joins them and configured newline terminates the record.
- `testPrintRecordEmptyIterable`: no values; `println()` emits the configured separator.
- `testPrintRecordsIterableOfRecordsAndValues`: array row then scalar; source prints each as its own record.
- `testPrintRecordsIterableOfIterableRows`: iterable row; source delegates it to `printRecord`.
- `testPrintCommentDisabledDoesNothing`: disabled comments; method returns without appending.
- `testPrintCommentAtRecordStartAndOnMultipleLines`: newline in comment; each line begins with comment marker and space.
- `testPrintCommentFinishesExistingRecordBeforeComment`: an active record is terminated before the comment.
- `testPrintlnResetsRecordForNextValue`: separator resets record state, so no delimiter precedes the next value.
- `testPrintEscapesLineBreakAndDelimiter`: delimiter and LF are escaped; LF becomes `n`.
- `testFlushAndCloseAreSafeForStringBuilder`: builder is neither `Flushable` nor `Closeable`; calls leave its contents unchanged.
