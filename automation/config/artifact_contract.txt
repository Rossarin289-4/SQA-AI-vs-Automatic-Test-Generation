EXPERIMENT ARTIFACT CONTRACT
============================

For each dataset, bug, and method:

automation/runs/<DATASET>/Bug-<BUG>/<METHOD>/

Methods:
- ChatGPT
- Gemini
- SA
- BPSO

Core generation artifacts:
- generated_test.java
- prompt.txt
- raw_output.txt

Algorithm methods:
- prompt.txt and raw_output.txt may be method-specific when the
  generation mechanism does not produce an AI conversational response.
- Algorithm generation metadata must remain traceable.

Evaluation artifacts:
- experiment.json
- result.csv
- status

Execution artifacts:

Buggy/
    execution.txt
    coverage.csv
    coverage.log

Fixed/
    execution.txt
    coverage.csv
    coverage.log

Optional artifacts may include:
- generation_seconds.txt
- generation.log
- compile.log
- evaluate.log
- suite_runner.log
- artifact_validation.log
- evaluation_wall_seconds.txt
- error.txt
- source hashes
- duplicate analysis
- method-specific generation configuration

DONE:
A method may be marked DONE only when the required evaluation
artifacts exist and contain valid evaluation data.

Evaluation requirements:
- Generated tests compile against the selected BUGGY version.
- Generated tests compile against the selected FIXED version.
- BUGGY and FIXED execution results are available.
- Evaluated test counts are available.
- Detection and FDR are derivable from the execution results.
- BUGGY and FIXED coverage are available when coverage execution
  succeeds.
- Timing data are recorded.

Traceability:

automation/runs/<DATASET>/master_results.csv
    |
    +--> Bug-<BUG>/<METHOD>/experiment.json
    |
    +--> generated_test.java
    +--> prompt.txt
    +--> raw_output.txt
    +--> result.csv
    +--> status
    |
    +--> Buggy/execution.txt
    +--> Buggy/coverage.csv
    |
    +--> Fixed/execution.txt
    +--> Fixed/coverage.csv
    |
    +--> selected Defects4J workspace/source metadata

Ground Truth:
The original Defects4J trigger test and source diff are evidence
for the defect definition only.

The original trigger test:
- must not be counted as a generated test
- must not be included in generated-suite FDR
- may be recorded in experiment metadata for traceability

Source integrity:
- Never modify the original Ground Truth files.
- Never manually modify Defects4J production source during evaluation.
- Evaluation must use the selected BUGGY and FIXED Defects4J versions.
