GENERATED TEST CONTRACT
=======================

Framework:
JUnit 4.12

Target:
A generated JUnit 4.12 test suite for one Defects4J bug.

Required:
- Valid Java source
- Valid JUnit 4.12 test class
- Must compile against the selected Defects4J project and bug version
- Must directly test behavior relevant to the modified source/method
- Must not modify production source code
- Must not modify original developer tests
- Must not copy the original Defects4J trigger test
- Must not invoke the original trigger test as part of evaluation
- Each generated test must have a unique JUnit test method name
- Generated tests must be independently designed from the defect context
- Generated tests must remain traceable to their generation source

Test count:
Number of valid JUnit test methods that compile and are included
in the evaluated generated suite.

Do NOT count:
- helper methods
- setup methods
- invalid tests
- compilation-failing tests
- original developer tests
- original Defects4J trigger test

Duplicate semantic tests:
If two generated tests are semantically identical, they count once
for evaluation while their original source traceability is preserved.

Evaluation:
Each valid generated test is executed independently on:
1. BUGGY version
2. FIXED version

Detection:
A generated test detects the defect when:
- BUGGY = FAIL
- FIXED = PASS

A test is not counted as detected when:
- BUGGY = PASS and FIXED = PASS
- BUGGY = FAIL and FIXED = FAIL
- either execution is ERROR
- compilation fails

Coverage:
BUGGY and FIXED coverage are measured separately using the
same Defects4J coverage mechanism for all methods.

Original trigger:
The original Defects4J trigger test is Ground Truth evidence only.
It is never counted as a generated test.
