FAULT DETECTION RATE
====================

evaluated_tests:
Number of generated JUnit test methods that:
1. are valid JUnit tests
2. compile successfully
3. execute on BUGGY
4. execute on FIXED
5. are therefore comparable between BUGGY and FIXED

detected_tests:
Number of evaluated test methods satisfying:

BUGGY = FAIL
FIXED = PASS

Formula:

FDR = detected_tests / evaluated_tests * 100

Examples:

evaluated = 4
detected = 1

FDR = 1 / 4 * 100
    = 25.0%

Important:

BUGGY PASS + FIXED PASS:
Not detected.

BUGGY FAIL + FIXED FAIL:
Not detected.

BUGGY ERROR:
Not evaluated.

FIXED ERROR:
Not evaluated.

Compile failure:
Not evaluated.

Original Defects4J trigger test:
Not included in generated-test denominator.

Duplicate semantic test:
Count once for evaluation.
Preserve original traceability.
