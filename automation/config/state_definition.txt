STATE MACHINE
=============

PENDING
  Initial state.
  No generation has started.

GENERATING
  Test generation is currently running.

COMPILED
  Generated test source compiled successfully.

EXECUTING_BUGGY
  Generated test suite is being executed on BUGGY.

EXECUTING_FIXED
  Generated test suite is being executed on FIXED.

EVALUATING
  BUGGY/FIXED results and coverage are being evaluated.

DONE
  All required experiment artifacts exist and evaluation completed.

FAILED
  Experiment failed at a recoverable stage.

SKIPPED
  Experiment was intentionally skipped.

Allowed normal flow:

PENDING
  -> GENERATING
  -> COMPILED
  -> EXECUTING_BUGGY
  -> EXECUTING_FIXED
  -> EVALUATING
  -> DONE

Failure may occur from:
GENERATING
COMPILED
EXECUTING_BUGGY
EXECUTING_FIXED
EVALUATING

FAILED experiments must retain all artifacts produced before failure.
